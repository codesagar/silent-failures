01 / WHEN TOOLS BREAK, WHAT DO AGENTS SAY?

Most models reported failure.
One mostly went silent.

Under heavy timeouts, four models acknowledged non-completion in 86–99% of failed episodes. Qwen ablated reached the tool-use loop limit without an answer in 91.5%.

Failure to finish and failure to report are different outcomes. A low rate of unsupported claims can coexist with almost no reporting.

02 / A DIFFERENT FAILURE CHANNEL

A missing response
can hide a real action.

Lost responses had higher unsupported-claim rates than explicit timeouts in four of five models at 50% assigned fault probability. GLM was the exception. The problem goes beyond visibly contradicting an error message.

LOUD · EXPLICIT ERROR

An injected call does not execute.

The injector raises a timeout, permission, rate-limit, or server error before the tool runs. The agent receives an error.

ServiceTimeout: Service temporarily unavailable: the request timed out.
QUIET · LOST RESPONSE

The tool runs. Its reply disappears.

The tool executes, including side effects. The injector replaces the return value with an empty list or string.

Tool result: [] or ""

WHY THIS MATTERS

“Done” needs evidence
of the whole task.

A claim can be unsupported because an action visibly failed, only part of the task finished, or a conclusion was never verified. Those are different evidence classes.

Inspect a lost-response episode →

Interpretation, not an isolated mechanism. Fault types change execution semantics, and failed-only groups contain different task mixes. This comparison does not prove visibility alone caused the difference.

03 / FOLLOW-UP, REGISTERED BEFORE THE PROBE

Silence at the cap
was not the last word.

After Qwen kept using tools instead of answering a status question, a second question with tools removed elicited acknowledgment of non-completion in 531 of 559 answers: 95.0%.

The narrower conclusion: original silence does not establish inability to acknowledge non-completion. The intervention changed both tool availability and the question; it is not a validated production fix.

A cap can also hide completed work. Across the full probe, 51 of 163 success-consistent stage-A answers described tasks already complete before the probe. Original episode labels were retained.

WHAT THIS STUDY CHANGES ABOUT THE QUESTION

Evaluate the outcome.
The report.
And the stopping rule.

These results suggest evaluating three things separately: whether the task finished, what the agent claimed, and whether the user received an answer before the budget expired.

This is evidence from five endpoints in one AgentDojo scaffold—not a model-family ranking or a claim about deceptive intent.
