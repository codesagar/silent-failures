Minimal light infographic composition. The full website uses one dark section to distinguish the post-hoc probe from the original protocol. Colors never substitute for labels. Rounded corners are small, borders provide grouping, and shadows/glows are absent.

## Diagram decisions before drawing

- Method: flowchart, editorial fit preset, mixed technical audience; six nodes. Repeated agent/tool exchanges are condensed, with the reduction stated in the caption. Two separate measurements converge at comparison. No semantic-pattern template exactly matches this measurement split, so the flowchart type governs directly.
- Conduct: three aligned dot-plot comparisons (bar-chart comparison grammar), fit preset, five model rows each. Identical 0–100% scales. Whiskers are the published task-cluster confidence intervals. Qwen is the focal model, not a general ranking winner or loser.
- Claim curves: five line-chart small multiples, fit preset, identical scales. Open baseline square separated from the injected series; actual unequal probability spacing retained. No smoothed trajectory.
- Error channels: quantitative comparison matrix with identical in-cell 0–100% bars, fit preset. Numerical cells keep the comparison readable without color. Detailed uncertainty lives in the adjacent published table.
- Probe: selection flowchart, fit preset, Qwen clean injected slice only. Static branches expose denominator changes. A separate narrow composition preserves the same counts for phones.
- Investigation timeline: semantic ordered HTML timeline. Event order is shown; spacing does not encode elapsed time.

All SVGs have unique titled/described accessibility references, visible static content, and viewBox-sized local scrolling. No animation is needed. No fresh scientific analysis is hidden in drawing code.
